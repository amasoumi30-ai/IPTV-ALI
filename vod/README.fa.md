# IPTV-ALI — بخش آزمایشی Movies و Series

این پوشه یک **نمونه عملی اولیه (MVP)** از درگاه خواندنیِ سازگار با بخش‌هایی از Xtream Codes است. شبکه‌های فایل اصلی `IPTV.m3u` را **نمی‌نویسد و تغییر نمی‌دهد**. با اتصال اپ سازگار از طریق Xtream API، شبکه‌ها، فیلم‌های درخواستی و سریال‌ها در سه فهرست مستقل تعریف می‌شوند. نمایش واقعی سه زبانه/سه بخش به قابلیت‌های اپ بستگی دارد. همه برنامه‌های IPTV از این API پشتیبانی نمی‌کنند.

## ملزومات

- Python 3.10 یا بالاتر در ویندوز یا سرور؛ وابستگی اضافی ندارد.
- فیلم‌های متعلق به خودت یا دارای اجازه انتشار/پخش، به صورت MP4 و سایر فرمت‌های قابل پخش؛ کدک هم باید با تلویزیون سازگار باشد.
- **برنامه IPTV که اتصال Xtream Codes را قبول کند.** صرف افزودن آدرس M3U به Smart IPTV لزوماً فیلم‌ها را به Movies/Series منتقل نمی‌کند.
- برای پخش بدون روشن ماندن کامپیوتر، برنامه و فایل‌های محلی باید روی **سرور همواره روشن** اجرا شوند؛ GitHub فقط کد و لیست را میزبانی می‌کند.

## گام ۱: فایل‌های فیلم و سریال را کپی کن

مثال ساختار فایل (این فایل‌های حجیم را داخل GitHub آپلود نکن):

```text
vod/
  media/
    movies/
      Comedy/
        My Movie (2025).mp4
      Another Movie.mp4
    series/
      My Series/
        Season 01/
          My Series S01E01.mp4
          My Series S01E02.mp4
        Season 02/
          My Series S02E01.mkv
```

برنامه هنگام درخواست فهرست، پوشه‌ها را می‌خواند و خودکار فیلم و فصل و قسمت را دسته‌بندی می‌کند. **در نام هر قسمت باید S01E01 یا S02E03 و مانند آن وجود داشته باشد.** فایل نامشخص وارد سریال نمی‌شود تا اشتباه دسته‌بندی نشود.

## گام ۲: افزودن یکجای لینک‌های آنلاین

برای آدرس مستقیمِ مجاز MP4/M3U8 می‌توانی به `vod/catalog.json` مراجعه کنی. قالب ورودی کامل در `vod/catalog.example.json` هست. `movies` آرایه فیلم‌هاست و `series` آرایه سریال‌ها با قسمت‌ها. با واردکردن فهرست کامل، نیازی نیست قسمت‌ها را به صورت تکی در IPTV ثبت کنی. لینک دارای DRM یا توکن کوتاه‌مدت ممکن است کار نکند.

## گام ۳: اجرای محلی در PowerShell

از پوشه اصلی مخزن:

```powershell
$env:VOD_USERNAME="myiptvuser"
$env:VOD_PASSWORD="choose-a-strong-different-secret"
python vod/portal.py
```

در این حالت فقط خود کامپیوتر (`127.0.0.1:8099`) به سرویس دسترسی دارد. برای آزمایش API در همان کامپیوتر:

```text
http://127.0.0.1:8099/player_api.php?username=myiptvuser&password=choose-a-strong-different-secret&action=get_vod_categories
```

## گام ۴: اتصال از تلویزیون / گوشی

اگر اپ تلویزیون از **Xtream Codes** پشتیبانی کرد، مشخصات معمولاً شامل Server URL و Username و Password می‌شود. آدرس درگاه باید از تلویزیون قابل دسترس باشد؛ `127.0.0.1` از تلویزیون به کامپیوتر اشاره نمی‌کند. برای آزمایش در شبکه خانگی می‌توانی فقط با فایروال محدود به LAN، `VOD_HOST=0.0.0.0` تنظیم کنی و `VOD_PUBLIC_URL` را با IP کامپیوتر و پورت تنظیم کنی. برای استفاده اینترنتی **حتماً HTTPS، فایروال و مجوز مناسب** لازم است، چون روش Xtream معمولاً رمز را در URL ارسال می‌کند.

نمونه URL ورودی: `http://LAN-IP:8099`، همراه با Username و Password. اگر برنامه صرفاً M3U بپذیرد، از `/get.php?...` می‌توان فهرست دریافت کرد اما تفکیک واقعی Movies/Series تضمین نیست.

## موارد مهم

- اطلاعات ورود را **در GitHub عمومی، فایل catalog.json یا داخل چت** قرار نده.
- این درگاه ساده برای آزمایش شخصی ساخته شده؛ پنل چندکاربره، مدیریت اشتراک، کنترل اتصال و DRM ندارد.
- لینک‌های آنلاین به صورت HTTP 302 به آدرس اصلی هدایت می‌شوند؛ پشتیبانی پخش در دستگاه به URL/کدک/هدرهای سرور اصلی بستگی دارد.
- برای فهرست Live TV از `../IPTV.m3u` تنها خواندن انجام می‌شود. ممکن است بعضی لینک‌های فعلی قطع باشند؛ این پروژه آن‌ها را تعمیر نمی‌کند.
- قبل از قرار دادن لینک دانلود/پخش فیلم، درباره حق نشر و اجازه انتشار مطمئن شو.
- برای اینترنت عمومی، رمزگذاری ارتباط و محدودسازی دستگاه‌ها لازم است. اجرای آزمایشی پیش‌فرض عمداً فقط روی localhost است.
